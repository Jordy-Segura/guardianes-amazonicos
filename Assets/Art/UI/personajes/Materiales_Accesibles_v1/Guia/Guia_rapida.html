2. Cómo colocar los controles

  • Panel claro para la consigna y las respuestas. Personaje al lado, sin cubrir el texto.
  • Una instrucción por paso. Etiquetas visibles: Escuchar, Pista, Señas y Lectura. Mismo orden y lugar en cada nivel.
  • En la demo: altura mínima de control 56 px CSS y separación 16 px. Son decisiones de diseño; verifica el tamaño físico y el escalado en el dispositivo final.
  • En Unity, como punto de partida para un Canvas de referencia 1920 × 1080: botones de al menos 240 × 88 unidades, texto 32–36 y separación 24. No equivalen automáticamente a píxeles CSS ni garantizan accesibilidad: prueba el tamaño real.
  • Estado seleccionado: borde más grueso + «✓ Seleccionada». Acierto: «✓ ¡Muy bien!». Error: mensaje de orientación y otro intento. El color nunca comunica solo.
  • Foco: contorno oscuro con separación clara. En Unity configura la navegación de todos los Selectable y un estado seleccionado visible; comprueba Tab/flechas/Enter en el equipo.

3. PNG en Unity

  1. Copia Personajes, Animaciones, Botones e Iconos a una carpeta nueva dentro de Assets.
  2. Selecciona los PNG de una secuencia: Texture Type Sprite (2D and UI), Sprite Mode Single, Mesh Type Full Rect. Mantén iguales Pivot y Pixels Per Unit en esa secuencia. Aplica.
  3. Para una escena, selecciona en orden los fotogramas de UN personaje y arrástralos a Scene para crear el clip. Samples: 24 para Explorador; 16 para los otros tres. Loop Time solo cuando quieras repetición. No mezcles secuencias ni añadas otra copia del fotograma inicial al final.
  4. Para un personaje dentro de Canvas, anima Image → Source Image o utiliza el reproductor opcional Unity/AnimacionPersonajePNG.cs: asigna destinoCanvas, los sprites en orden y la velocidad correspondiente. Ese script empieza detenido y con Reducir movimiento activo.
  5. En el reproductor opcional, conecta un Toggle a EstablecerReducirMovimiento(bool), un botón a ReproducirUnCiclo y otro a Pausar. Desactiva Reducir movimiento antes de reproducir. Usa un solo sistema de reproducción por personaje.
  6. Para cada Button: base sin texto en Image; añade el icono como imagen hija y la etiqueta como texto editable. Usa Sprite Swap para Normal/Foco/Pulsado/Deshabilitado según corresponda. Conserva la misma área interactiva en todos los estados.

4. Opciones necesarias

Reducir movimiento, pausa, fondo sencillo, texto ampliable y contraste alto. La demostración incluye estas opciones. Audio y texto deben explicar la misma consigna. Evita destellos y sonidos automáticos. Señas necesita videos reales revisados para la lengua de señas de los usuarios.

5. Lo que falta validar

Pruebas de comprensión y selección con niños y docentes; uso con teclado y dispositivos de apoyo; lector de pantalla, nombres y orden de navegación en Unity; audio y señas; lectura y controles a tamaño real en cada dispositivo. No se afirma que el paquete sea adecuado para todas las discapacidades.
