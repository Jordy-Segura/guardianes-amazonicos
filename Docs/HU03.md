- Ayuda modal con texto e imagen, bloqueo de controles y devolución del foco. Señas usa VideoPlayer → RenderTexture → RawImage cuando existe el MP4 local; mientras falta, muestra un aviso.

Campos JSON aditivos: retoGuacamayoCompletado, retoJaguarCompletado y retoPlatanoCompletado; los dos últimos preservan la compatibilidad con develop. JSON anteriores que no contienen estos campos los cargan como false. No se cambia el número global de niveles ni se usa PlayerPrefs para el progreso.
- La composición corregida sigue la captura de actividad de la guía: fondo N1_Conozco_la_selva del ZIP, personajes a la izquierda, globo arriba, imagen enmarcada a la derecha y tres tarjetas debajo; se quita la franja de estado ajena a la referencia y se conserva el brillo de las tarjetas que no se eligieron.
